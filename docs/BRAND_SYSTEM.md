# Brand System

## Direction

Life Track should feel like a reflective field journal that unfolds into an analytical memory board.

- First impression: calm, personal, paper-like, forest-toned.
- Secondary layer: intelligent, connected, copper/teal signal accents.
- Core motif: pinned days connected by sparse meaningful strings.

## Palette

- Paper: `#F4EFE4`
- Paper elevated: `#FFF9ED`
- Forest ink: `#14352B`
- Moss: `#607C58`
- Sage: `#A8B79A`
- Cork: `#C09A62`
- Copper: `#B96F3C`
- Electric teal: `#38C7B7`
- Pale gold: `#D9B95B`
- Rust: `#A14E38`

## UI Rules

- Journal-first: Today starts with writing, tasks, and only the most important metrics.
- Expandable intelligence: analytics and recall appear through detail expansion.
- Corkboard surfaces are reserved for memories and recall, not every screen.
- Connection lines should be sparse and meaningful.
- Use subtle texture only; avoid heavy skeuomorphic cork or notebook styling.
- Use system typography for readability, with restrained stamped/date accents.
